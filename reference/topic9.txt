# Задание 9 — Уравнения и системы уравнений

## Подтема 1: Линейные уравнения
Пример 1: Решите уравнение: 2 − 3(2x + 2) = 5 − 4x
Решение: Раскрыть скобки, перенести слагаемые, упростить
Ответ: −4.5

Пример 2: Решите уравнение: 3x + 5 + (x + 5) = (1 − x) + 4
Решение: Раскрыть скобки, привести подобные, решить
Ответ: −1

Пример 3: Решите уравнение: 10x + 9 = 7x
Решение: Перенести переменные в левую часть
Ответ: −3

Пример 4: Решите уравнение: −x − 2 + 3(x − 3) = 3(4 − x) − 3
Решение: Раскрыть скобки обеих частей, упростить
Ответ: 4

Пример 5: Решите уравнение: 10(x − 9) = 7
Решение: Раскрыть скобку, разделить обе части
Ответ: 9.7

## Подтема 2: Квадратные уравнения
Пример 1: Найдите корни уравнения 2x² − 10x = 0. Если корней несколько, запишите их в ответ без пробелов в порядке возрастания.
Решение: Вынести x за скобку: x(2x − 10) = 0, получить x = 0 и x = 5
Ответ: 05

Пример 2: Решите уравнение x² + 3x = 4. Если корней несколько, запишите их в ответ без пробелов в порядке возрастания.
Решение: Преобразовать в стандартный вид x² + 3x − 4 = 0, применить теорему Виета
Ответ: −41

Пример 3: Решите уравнение x² = 2x + 8. Если корней несколько, запишите их в ответ без пробелов в порядке возрастания.
Решение: Привести к виду x² − 2x − 8 = 0, корни −2 и 4
Ответ: −24

Пример 4: Решите уравнение x² + 7x − 18 = 0. Если корней несколько, запишите их в ответ без пробелов в порядке возрастания.
Решение: Применить теорему Виета или дискриминант, корни −9 и 2
Ответ: −92

Пример 5: Найдите корни уравнения x² + 4 = 5x. Если корней несколько, запишите их в ответ без пробелов в порядке возрастания.
Решение: Привести к виду x² − 5x + 4 = 0, корни 1 и 4
Ответ: 14

## Справка: Методы решения
- Линейное уравнение ax + b = 0 решается переносом: x = −b/a
- Квадратное уравнение ax² + bx + c = 0 решается через дискриминант D = b² − 4ac или теорему Виета
- Для произведения x(ax + b) = 0: либо x = 0, либо ax + b = 0
- Теорема Виета: если x₁ и x₂ корни x² + px + q = 0, то x₁ + x₂ = −p и x₁ · x₂ = q
