# Задание 8 — Числа, вычисления и алгебраические выражения

## Подтема 1: Степени и корни
Пример 1: Найдите значение выражения 5√11 · 2√2 · √22
Решение: Используются свойства корней
Ответ: 220

Пример 2: Чему равно значение выражения (3√2)²?
Решение: Применяется определение степени
Ответ: 18

Пример 3: Найдите значение выражения 4⁻¹⁰ · (4³)⁴
Решение: Используются свойства степеней (произведение, степень степени)
Ответ: 16

Пример 4: Найдите значение выражения (√11 - 3)(√11 + 3)
Решение: Применяется формула разности квадратов (a - b)(a + b) = a² - b²
Ответ: 2

Пример 5: Найдите значение выражения (√18 + √2) · √2
Решение: Раскрытие скобок и упрощение корней
Ответ: 8

## Справка: Основные правила
- Произведение корней: √a · √b = √(ab)
- Свойства степеней: aⁿ · aᵐ = aⁿ⁺ᵐ, (aⁿ)ᵐ = aⁿᵐ
- Формулы сокращённого умножения: (a - b)(a + b) = a² - b²
- Отрицательная степень: a⁻ⁿ = 1/aⁿ
